The executive summary

A portfolio of ideas you can check, not just read.

Most technical claims are taken on trust. This repository replaces trust with evidence: twenty-four compact implementations, each paired with an automated experiment that tests it against something real. It is an executable curriculum, a due-diligence toolkit, and a demonstration that the foundations are understandable.

One idea per experiment

Least action, quantization, attention caches, retrieval, relativity, GANs, ChaCha20 — each isolated, explained, and implemented without a framework hiding the mechanics.

Verified against reality

CODATA measurements, RFC 8439 test vectors, real order-book data, live exchange quotes, 20 Newsgroups, Riemann zeros, and a full GPS constellation. Every check leaves a receipt.

Small enough to read

Pure Python and NumPy, CPU-only, no cloud account. The full suite runs in under nine minutes on a laptop and produces the same JSON the website displays.

Run it yourself

Three commands to a verified lab.

Python 3.12 and a laptop. The smoke run takes about half a minute; the full suite finishes in under nine. Every number on this page is regenerated locally.

terminal
# 1. install the package
python -m venv .venv && source .venv/bin/activate
pip install -e .

# 2. prove it works in 30 seconds
python scripts/run_all.py --smoke

# 3. run all 24 experiments (~9 minutes)
python scripts/run_all.py --all
python -m pytest -q

Prefer containers? docker compose up --build runs the same suite. Results land in results/; this website reads them from assets/site-data.js.

1

Install. A virtual environment plus pip install -e .. NumPy, SciPy, scikit-learn, matplotlib, and Pillow — all CPU.

2

Verify. The smoke run exercises representative experiments; the full run writes every JSON record and refreshes the summary.

3

Explore. Open results/, read the checks, change a parameter, rerun one experiment, and see what breaks.

4

Publish. Push to GitHub, then Settings → Pages → Deploy from a branch → main / (root). index.html forwards to this page.
